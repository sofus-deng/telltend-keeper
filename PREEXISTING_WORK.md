# Pre-existing Work Disclosure

Telltend Keeper is a new implementation created for the **Agents for Humans Hackathon** during the submission period.

## What predates this repository

The following product-level work existed before this hackathon implementation began:

- the Telltend product concept and name;
- the target problem of governed conversational website operations;
- the intended customer focus on website studios, web agencies, and small-business website operators;
- product specifications for concepts such as a site capability manifest, structured change sets, preview, approval, publication, verification, rollback, and auditability;
- internal capability planning and prior competition-fit analysis.

These materials are product specifications and planning artifacts. They are not copied wholesale into this public repository.

## Implementation baseline at repository creation

At the start of Telltend Keeper:

- there was no canonical Telltend runtime repository;
- there was no completed Telltend implementation of the Keeper hero loop;
- there was no completed Strands integration for Telltend;
- there was no completed AgentCore deployment for Telltend;
- there was no production customer website used by this submission.

The implementation submitted from this repository is intended to be built during the hackathon submission period.

## Source-lineage rule

If any pre-existing code, asset, fixture, or third-party material is later introduced, it must be recorded in `docs/source-lineage.md` with its source, version or commit when applicable, license, purpose, and whether it is modified.

Private product strategy, full internal capability inventories, pricing, GTM material, and unreleased roadmap documents are not part of this repository.
